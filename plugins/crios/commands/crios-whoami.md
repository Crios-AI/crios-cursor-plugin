# Who am I in Crios

Call the `whoami` tool.

Report the name, email, role, and active organization. If the tool says the base URL or token is missing, explain how to set `CRIOS_BASE_URL` and `CRIOS_TOKEN` in the plugin configuration. Do not ask the user to paste the token into chat.
